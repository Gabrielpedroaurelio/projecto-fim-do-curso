Guia Técnico de Continuidade do Projecto

1. Introdução

Este documento serve como manual de integração para desenvolvedores. O sistema foca em escalabilidade, segurança e estética profissional.

2. Arquitetura do Sistema

  • Core: Django 5.2.4.
  • Interface Admin: Django Unfold (Modern UI).
  • API Layer: Django REST Framework.
  • Segurança: SimpleJWT + SchoolAuth.
  • Documentos: xhtml2pdf engine.

3. Estrutura de Pastas (Backend)

  • apis/models/: Modelagem modular (Financeiro, Académico, Documentos).
  • apis/services/: Camada de Serviços (PDFService, DocumentService).
  • apis/signals/: Gatilhos automáticos (ex: Geração de PDF no pagamento).

4. Como Iniciar

# 1. Instalar dependências
pip install -r requirements.txt

# 2. Migrar o banco
python manage.py migrate

# 3. Iniciar Servidor
python manage.py runserver

5. Fluxo de Geração de Documentos

O fluxo é automatizado: Solicitação -> Pagamento -> Signal (Post-Save) -> PDFService -> Media Storage.
